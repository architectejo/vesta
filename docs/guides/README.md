# Guides utilisateur par rôle (tâche 5.5)

Guides courts, orientés tâches, pour les rôles principaux de Vesta. Basés sur les écrans réellement implémentés (code frontend + `docs/ecrans/`) — aucune capture d'écran (pas d'accès navigateur au moment de la rédaction), les étapes sont décrites en clair. Si un écran diffère de ce qui est décrit ici, le code fait foi.

- [Président](guide-president.md)
- [Trésorier / Trésorier adjoint](guide-tresorier.md)
- [Coach](guide-coach.md)
- [Joueur](guide-joueur.md)
- [Médecin](guide-medecin.md)

Rôles non couverts par un guide dédié (périmètre restreint, ou proches d'un rôle déjà documenté) : Vice-président (voir guide Président, section « Ce que vous partagez »), Directeur sportif (mercato, suivi sportif en lecture seule), Intendant (matériel, voir `docs/ecrans/logistique.md`), Capitaine (pointage et incidents, voir guide Coach). À compléter séparément si le client le demande.
